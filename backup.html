Application backup
Exports operational PostgreSQL data to a portable JSON file
Founder/Admin

The export preserves record IDs, relationships, document numbering and operational history. The JSON file contains sensitive business and finance data—store it securely. Restore is intended for the same Supabase project, or a target where matching Auth user IDs already exist.

Included: ERP database records and document storage paths. Excluded: Supabase Auth credentials/sessions, actual Storage file bytes, secrets and hosting configuration. Missing Auth identities are detected during validation and block restore.
Document Storage backup
Downloads actual private erp-documents file bytes into one ZIP
Founder/Admin

Use this together with the application JSON backup. The ZIP contains every file in the private ERP document bucket plus a manifest with paths, sizes, MIME types and CRC32 checksums.

Browser ZIP backup is capped at 250 MB to avoid exhausting device memory. For larger buckets, use the Supabase CLI/platform backup workflow.
